# Frontend CarRental

Frontend simples (HTML/CSS/JS vanilla) para a **CarRental API**.

## Funcionalidades

- Listar e cadastrar clientes
- Listar aluguéis
- Criar aluguel
- Pagamentos

## Como rodar

```bash
npm install
npm start
```

Ou abra o `index.html` diretamente no navegador (requer que a API esteja rodando em `http://localhost:8080`).

## API Base

A API é consumida em `http://localhost:8080`. Para mudar, edite a variável `API_BASE` no `js/app.js`.
